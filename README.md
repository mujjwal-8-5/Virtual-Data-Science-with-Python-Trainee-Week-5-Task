# Week 5 — Deep Learning Application in Data Science

## Project
**Fashion-MNIST clothing image classification using a Convolutional Neural Network (CNN).**

The model classifies 28×28 grayscale images into ten clothing/accessory categories. This repository contains the training script, a report, architecture diagram, and folders for generated metrics and plots.

## Quick start
Recommended: Python 3.10 or 3.11 in a virtual environment.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt
python src/train.py
```

The first run downloads Fashion-MNIST via Keras, so internet access is required. Training may take several minutes depending on your CPU/GPU. TensorFlow GPU support depends on your operating system and setup; CPU training is supported.

## Outputs generated by the script
- `results/metrics.json`: test loss, accuracy, per-class precision/recall/F1, confusion matrix.
- `results/predictions.csv`: true and predicted labels and confidence for every test image.
- `results/best_model.keras`: checkpoint with best validation loss.
- `figures/training_curves.png`: training/validation loss and accuracy.
- `figures/confusion_matrix.png`: confusion matrix on the test set.

Generated results are not committed by default; run the script to produce them. Do not report metrics as measured until you have run the code and copied the actual values into your final submission.

## Dataset
Fashion-MNIST is a public benchmark dataset distributed through `tensorflow.keras.datasets.fashion_mnist`. It contains 70,000 grayscale 28×28 images: 60,000 training examples and 10,000 test examples, with ten classes. The test set is held out from training and validation.

## Reproducibility and integrity
A random seed of 42 is set for TensorFlow/Keras. Some small differences may still occur across hardware and software versions. The report describes the experiment and evaluation procedure; run the script and use its generated metrics for your final results.
