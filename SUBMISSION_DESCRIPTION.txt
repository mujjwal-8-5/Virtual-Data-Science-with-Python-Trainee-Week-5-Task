This report documents an end-to-end deep learning project that classifies clothing and accessory images using the public Fashion-MNIST dataset and a Convolutional Neural Network (CNN) implemented with TensorFlow/Keras. The report introduces the classification problem, describes the dataset and its ten categories, explains image normalization and input shaping, and justifies the selected network architecture. The CNN uses two convolutional blocks with ReLU activations and max-pooling, followed by a flattening layer, a 128-unit dense layer, dropout regularization, and a ten-class softmax output.

The training process is documented with the Adam optimizer, sparse categorical cross-entropy loss, a batch size of 128, a maximum of 15 epochs, a 10% validation split, early stopping, and model checkpointing. The official test set remains separate from training and validation to provide a fair final evaluation. The Python script reports test loss and accuracy, per-class precision, recall and F1-score, and a confusion matrix. It also exports predictions with confidence scores and creates training/validation curves for examining convergence and possible overfitting.

The critical analysis discusses challenges such as visually similar clothing classes, overfitting, limited image resolution, runtime constraints, data leakage, and reproducibility. It describes how validation monitoring, dropout, checkpointing, a compact model, and a fixed random seed help address these concerns. The repository includes the Word report, complete runnable training script, dependency list, README, architecture diagram, and output folders for generated metrics and figures. Run the script before final submission and copy the actual measured results into the report; no test scores are claimed without execution. This work demonstrates the major stages of a supervised deep learning workflow, from data preparation and model design to evaluation and reflection.
